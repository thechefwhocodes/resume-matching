# Ground Truth

This folder anchors the eval suites. We commit two things:

1. **5 hand-curated job-id picks** -- one JSON file per locked resume.
2. **5 hand-labeled `ResumeProfile`s** -- a single `profiles_handlabeled.json`.

Together they cover both *retrieval / rerank quality* (do we surface the
right jobs?) and *extractor quality* (do we extract the right structured
profile from text?).

## File: `<resume-slug>.json`

One per locked resume. Generated by **Claude Opus 4** with the prompt below
and **lightly hand-checked** (verify that every job_id exists in
`data/jobs.json` -- the validation script does this for you).

Schema (mirrors `ExpectedMatch` in `src/types/index.ts`):

```json
{
  "resume_file": "experienced/senior-backend-engineer.txt",
  "expected_job_ids": [
    "<job_id_1>",
    "<job_id_2>",
    "<job_id_3>",
    "<job_id_4>",
    "<job_id_5>"
  ],
  "notes": "Strong DAG/distributed-systems fit. Top-5 reflect Senior+ Backend roles at SF/Seattle Series-B+ shops."
}
```

`expected_job_ids` is the ranked top-5 hand-curated set. Order matters for
NDCG/MRR.

## File: `profiles_handlabeled.json`

```json
[
  {
    "resume_file": "experienced/senior-backend-engineer.txt",
    "profile": {
      "years_experience": 8.0,
      "primary_category": "Backend",
      "secondary_categories": ["DevOps"],
      "seniority": "Senior",
      "needs_h1b_sponsorship": false,
      "open_to_remote": false,
      "location_city": "Seattle, WA",
      "skills": ["go","python","postgres","kafka","kubernetes","aws","grpc","redis"],
      "summary": "Senior Backend / Distributed Systems engineer, US-based."
    }
  }
]
```

5 entries total, one per locked resume.

## How to (re)generate the picks via Claude Opus 4

Use this prompt verbatim with `claude-opus-4` (or the closest available
Claude Opus you have access to). One run per resume.

```text
You are a senior tech recruiter helping me build ground-truth labels for a
resume-to-job matching evaluation. I will give you (a) one candidate's
resume and (b) a JSON array of 300 job postings. Your job is to return the
TOP 5 jobs from the array that this candidate is most likely to be a strong
fit for, ranked best to worst.

Hard rules:
  - Use only the provided 300 jobs. Do not invent IDs.
  - Reject jobs whose `status` is not "active".
  - Reject jobs that require visa sponsorship the candidate cannot accept,
    or whose `yoe_min` exceeds the candidate's experience by more than 2.
  - Among survivors, prefer category alignment > seniority alignment >
    location > equity. Use greenFlags / redFlags / idealCompanies as tiebreakers.

Output ONLY valid JSON with this shape:
{
  "resume_file": "<the path I told you>",
  "expected_job_ids": ["<id_1>","<id_2>","<id_3>","<id_4>","<id_5>"],
  "notes": "<2-3 sentences of why these top-5; cite specific signals>"
}
```

After generation, run the validator:

```bash
make eval-validate-gt
```

(implemented in `eval/validate_ground_truth.py`).
